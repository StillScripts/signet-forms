# Memory

This directory is intentionally repository-light.

## Git policy

- Only `README.md` files in `memory/` are committed.
- All other files in this directory are ignored by `.gitignore`.

## Purpose

Use `memory/` for local or personal working memory that should not be shared in git history by default.

## Structure

- `context/README.md`
- `people/README.md`
- `projects/README.md`
